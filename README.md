# ESP32 Smart EV Charging Cable Temperature & Pilot Monitor

> ESP32-based EV charging health monitor for cable/connector temperature, control-pilot signal quality, charging state, and fault detection.

## Overview

This project implements a low-voltage monitoring node for an EV charging interface. An ESP32 samples an NTC thermistor, estimates connector/cable temperature, measures a **conditioned** control-pilot waveform, filters noisy measurements, evaluates a charging-state machine, logs faults, and exposes telemetry through a local Wi-Fi dashboard.

The project monitors an EV charging interface; it does **not** switch mains power or directly connect an ESP32 GPIO/ADC to an EVSE pilot line.

```text
                    │
 Pilot conditioning ├──> ESP32 ──> State Machine ──> OLED
                    │      │
 Fault input ───────┘      └────> Wi-Fi Dashboard
                                   │
                                   └────> Event log / telemetry
```

### Safety boundary

The pilot input is represented by a **safe, low-voltage conditioned signal** generated by an isolated/suitable interface stage. For a real EVSE, use an appropriate certified front-end designed for the pilot interface and applicable safety requirements. This repository does not provide mains-side switching or an EVSE implementation.

## Hardware

Recommended prototype hardware:

- ESP32 development board
- 10 kΩ NTC + resistor divider
- 0.96" I²C OLED
- Logic-level conditioned PWM test source for pilot input
- Push button for fault injection/reset
- Optional buzzer/LED
- 5 V USB supply

## Signal Model

The monitor expects a conditioned PWM signal representative of a control-pilot input.

Default software expectations:

- Nominal frequency: 1 kHz
- Valid duty range: 5–95%
- Warning temperature: 55 °C
- Critical temperature: 70 °C
- Sensor open/short detection: enabled

These are **software-demo thresholds**, not EVSE safety limits.

## Build

This repository is structured for **ESP-IDF**.

```bash
idf.py set-target esp32
idf.py build
idf.py flash monitor
```

Run host-side tests with a normal C compiler using the supplied test source and pure-logic modules.

## Demonstration

1. Power the ESP32 from USB.
2. Connect the NTC divider.
3. Feed a safe 1 kHz conditioned PWM test signal to the pilot input.
4. Open the serial monitor and Wi-Fi dashboard.
5. Vary the NTC temperature or simulated ADC value.
6. Inject invalid pilot duty/frequency conditions.
7. Verify state transitions and fault counters.
8. Confirm the OLED and dashboard stay synchronized.
